# 📝 Crib Note

> 책상 밑으로 몰래 건네주는 대사 쪽지.

SillyTavern 답변 추천 확장. 지금까지의 대화를 읽고 **내 캐릭터의 답변 후보**와 **다음 전개 아이디어**를 쪽지로 건네줘요.

## 설치

SillyTavern → 확장(Extensions) → **Install extension** → 아래 주소 붙여넣기

```
https://github.com/Near7707/CribNote
```

## 사용법

1. 입력창 오른쪽 📝 쪽지 버튼을 누르면 추천 패널이 열려요
2. 분위기 선택: 평범 / 긴장 / 로맨스 / 코믹 / 반전 / 🎲 랜덤
3. 필요하면 "추가 요청"에 한 줄 적고 **쪽지 받기**
4. 쪽지를 누르면 입력창에 들어가요
   - 💬 대사 쪽지 → 그대로
   - 🎬 전개 쪽지 → `(OOC: …)` 형태로
   - 기존 입력 내용은 선택한 쪽지 하나로 바뀌어요. 다른 쪽지를 눌러도 이어 붙지 않아요.

### 패널 기능
- **답변 언어 칩**: 한글 → EN → 대화 따라 순서로 전환
- 📇 **캐릭터 요약**: 캐릭터 카드를 AI로 한 번 짧게 정리해서 저장 → 추천할 때 카드 원문 대신 사용 (직접 수정 가능, 카드가 바뀌면 알려줌)
- ✏️ **내 캐릭터 메모**: 채팅방마다 따로 저장되는 성격·말투 메모
- 👁 **보낸 프롬프트 보기**
- 쪽지를 쓰는 중엔 버튼이 **취소**로 바뀜. 연결 프로필과 현재 Chat Completion / Text Completion 연결은 Crib Note 요청만 중단해요. 개별 중단을 지원하지 않는 구형·기타 API는 결과를 취소하고, 기존 요청이 끝날 때까지 기다려요.
- 받은 쪽지는 **같은 턴에서는** 닫거나 새로고침해도 유지돼요. 메시지를 보내거나 상대 답변이 새로 오면 지워져요. 스와이프·메시지 수정·삭제 때도 이전 맥락의 쪽지를 정리해요. 쪽지를 눌러 입력창에 넣기만 했을 때는 유지돼요.

### 설정 (확장 메뉴 → Crib Note)
- 추천에 쓸 연결 프로필 (비우면 현재 연결 사용)
- 답변 후보 / 전개 아이디어 개수
- 읽을 최근 메시지 수, 최대 응답 토큰
- 답변 후보 언어 / 전개 아이디어 언어 따로 설정
- 페르소나 설명 · 캐릭터 카드 참고 여부
- 🎲 랜덤에 포함할 분위기
- 쪽지를 고르면 패널 자동으로 닫기 (기본 켜짐) / 패널 바깥을 누르면 닫기 (기본 꺼짐)

## 참고
- 캐릭터 메시지 속 상태창·HTML·코드블록은 자동으로 걸러서 읽어요
- 띵킹 모델을 쓰면 결과가 잘릴 수 있어요. 그럴 땐 최대 응답 토큰을 2500~3000으로 올려주세요
- 응답이 잘리거나 형식이 맞지 않으면 오류를 안내해요. 쪽지 개수를 줄이거나 최대 응답 토큰을 늘려 다시 받아주세요.
