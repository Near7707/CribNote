# 📝 Crib Note

> 책상 밑으로 몰래 건네주는 대사 쪽지.

SillyTavern 답변 추천 확장이에요. 지금까지의 대화를 읽고 **내 캐릭터가 할 만한 대사**와 **다음 전개 아이디어**를 쪽지로 건네줘요.

## 설치

SillyTavern → 확장(Extensions) → **Install extension** → 아래 주소 붙여넣기

```
https://github.com/Near7707/CribNote
```

## 빠르게 써보기

1. 입력창 오른쪽 📝 버튼을 눌러 패널을 열어요
2. 분위기를 고르고 **쪽지 받기**
3. 마음에 드는 쪽지를 누르면 입력창에 들어가요

## 기능

### 쪽지 받기

- **분위기**: 평범 · 긴장 · 로맨스 · 코믹 · 반전 · 🎲 랜덤. 내 분위기를 직접 만들 수도 있어요 (예: 도깨비 장난)
- **길이**: 보통 → 짧게 → 길게
- **형식**: 자유 → 대사만 → 행동만
- **언어**: 한글 → EN → 대화 따라
- **추가 요청**: "탈출하는 쪽으로" 처럼 한 줄 적으면 반영해요

### 쪽지 쓰기

- 💬 **대사 쪽지**는 그대로 입력창에 들어가요
- 🎬 **전개 쪽지**는 두 가지 방식 중 고를 수 있어요 (패널의 `전개` 칩)
  - **OOC**: 입력창에 `(OOC: …)`로 넣어요
  - **몰래**: 입력창은 그대로 두고, 다음 답변에만 AI한테 몰래 전달해요. 채팅 기록에 안 남아요

### 쪽지마다 붙은 도구

| | |
|---|---|
| 📌 | 보관함에 고정 |
| 🔄 | 이 쪽지만 다시 |
| ✂️ | 더 짧게 |
| 🔥 | 더 대담하게 |

### 그 밖에

- 📌 **보관함**: 핀 찍힌 쪽지가 있으면 자동으로 펼쳐 보여요. 핀은 각 스와이프 응답에 따로 보관되어 원래 응답으로 돌아오면 복구돼요. 다음 메시지로 진행하거나 메시지를 수정·삭제하면 일반 쪽지와 함께 정리돼요
- 📇 **캐릭터 요약**: 긴 캐릭터 카드를 한 번 짧게 정리해두고 그걸로 추천해요. 직접 고칠 수 있고, 페르소나를 바꿔도 이름이 알아서 맞춰져요
- ✏️ **내 캐릭터 메모**: 채팅방마다 따로 적는 성격·말투 메모
- 👁 **보낸 프롬프트 보기**
- 캐릭터 메시지 속 상태창·HTML·코드블록은 자동으로 걸러서 읽어요
- 따로 표시한 캐릭터 속마음도 추천에 보내지 않아요. `<Inner_Info>`, `<inner_thought>`, `<thought>` 같은 블록과 해당 class/id가 있는 HTML 블록, `💭 …` · `속마음: …` · `Inner thoughts: …` 형태의 별도 줄을 제외해요. 여러 줄 속마음은 태그 블록으로 감싸주세요. 유저 메시지에 쓴 자신의 속마음은 참고할 수 있어요

## 설정

확장 메뉴 → **Crib Note**

- 추천에 쓸 연결 프로필 (비우면 지금 연결된 API 사용)
- 대사 / 전개 쪽지 개수
- 읽을 최근 메시지 수, 최대 응답 토큰
- 대사 / 전개 쪽지 언어
- 페르소나 설명 · 캐릭터 카드 참고 여부
- 내 분위기 만들기, 🎲 랜덤에 넣을 분위기
- 전개 쪽지 방식 (OOC / 몰래)
- 쪽지를 고르면 패널 닫기 (기본 켜짐), 패널 바깥을 누르면 닫기 (기본 꺼짐)

## 알아두면 좋은 것

- 받은 쪽지는 패널을 닫거나 새로고침해도 남아 있어요. 다른 스와이프로 이동하면 그 응답의 쪽지를 보여주고, 원래 응답으로 돌아오면 이전 쪽지와 핀·선택 표시를 복구해요. 다음 메시지로 진행하면 정리돼요
- **쪽지가 안 나오거나 잘려요** → 띵킹 모델은 생각하느라 토큰을 많이 써요. 최대 응답 토큰을 2500~3000으로 올리거나 쪽지 개수를 줄여보세요
- **요약에 예전 페르소나 이름이 보여요** → 📇에서 **다시 만들기**를 한 번 눌러주세요

**v0.9.6**
- 마지막 메시지를 별도로 표시해 이전 대화와 말투 예시에 대한 답변이 섞이지 않도록 추천 프롬프트 개선
- 분위기와 선택지 다양성보다 현재 상황과 대화의 연속성을 우선하도록 보완
- 상태창·속마음만 남은 메시지는 문맥 개수에 포함하지 않도록 정리

**v0.9.5**
- 캐릭터 스와이프 생성 취소 후 원래 답변으로 복구되면 열린 패널에서도 쪽지·핀·선택 표시를 바로 복원

**v0.9.4**
- 별도 표시한 캐릭터 속마음 제외 형식 확대
- 상대의 속마음을 유저가 아는 것처럼 답하지 않도록 추천 지침 보완

**v0.9.3**
- 스와이프 응답별 쪽지와 핀을 보관하고 원래 응답으로 돌아오면 복구
